# sutura-public

Sutura - Plastic Surgery uygulamasının herkese açık küçük deposu (GitHub Pages). Yayıncı: Pergamed (https://pergamed.com).

- `index.html`, `privacy.html`, `terms.html`: **yönlendirme sayfaları.** Destek, gizlilik ve koşullar pergamed.com'dadır (`/support/`, `/privacy/`, `/terms/`; Türkçe tarayıcıda `/tr/destek/`, `/tr/gizlilik/`, `/tr/kosullar/`).
- `data/congresses.json`: kongre tarihleri ve abstract son başvuru tarihleri. Düzenli olarak resmi sitelerden kontrol edilir; resmi sitede olmayan tarih `null` kalır, tahmin edilmez.
- `data/journals.json`: dergi listesi ve ISSN'ler (son sayılar uygulamada Crossref'ten okunur).

Uygulama veri dosyalarını bu deponun GitHub Pages adresinden okur. Bu depoda kişisel veri bulunmaz. İletişim: support@pergamed.com.
